# cellstats


## Environment Setup

The execution environment for the notebooks included in this repository can be set up using Pixi.
For Pixi installation instructions, please refer to https://pixi.sh/latest/installation/.

## Usage

After installing Pixi, launch `marimo` with the following command:

```bash
pixi run marimo edit notebooks/main.py
```

Or alternatively:
```bash
pixi run --environment development marimo edit notebooks/main.py
```


A browser window will open, allowing you to edit and run the notebook from your browser.
